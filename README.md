# DrawAPLAY

Sketch American football plays fast — get smooth, broadcast-quality animated play diagrams back.

See [SPEC.md](./SPEC.md) for the full product & engineering spec.

## Develop

```sh
npm install
npm run dev
```

## Verify

```sh
npm run lint    # oxlint
npm run build   # typecheck (tsc -b) + production build
```
